# Security Policy

## Supported Versions

Security fixes are currently provided for the latest `2.x` release. Older
major versions are not supported.

| Version | Supported |
| ------- | --------- |
| 2.x.x   | :white_check_mark: |
| 1.x.x   | :x:        |
| < 1.0.0 | :x:        |

## Reporting a Vulnerability

Security bugs in `itscalledsoccer` are taken seriously. We appreciate your
efforts to responsibly disclose your findings.

To report a security issue, please use the GitHub Security Advisory
["Report a Vulnerability"](https://github.com/American-Soccer-Analysis/itscalledsoccer/security/advisories/new)
tab.

Please do not disclose vulnerabilities through public GitHub issues, pull
requests, or discussions. We aim to acknowledge valid reports within 7 days.
After the initial reply, we will provide updates as the report is investigated,
fixed, and disclosed. Security fixes will be included in the release notes,
along with any affected versions and upgrade guidance.

Report security bugs in third-party modules to the person or team maintaining
the module.
